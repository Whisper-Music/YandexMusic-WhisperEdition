# Yandex Music Desktop

> Кастомный дизайнерский клиент для Яндекс Музыки с расширенными возможностями персонализации интерфейса.

Yandex Music Desktop — неофициальный сторонний клиент для Яндекс Музыки в редакции Whisper Muisc, созданный с упором на внешний вид, персонализацию и удобство использования.

Приложение позволяет настроить интерфейс под себя, изменить внешний вид плеера и сделать работу с музыкой более комфортной.

## Дисклеймер

**Yandex Music Desktop является неофициальным сторонним проектом.**

Проект не связан с Яндексом, не разрабатывается и не поддерживается компанией Яндекс.

Название «Яндекс Музыка», логотипы, музыкальные произведения, обложки, метаданные и другие материалы сервиса принадлежат их соответствующим правообладателям.

Лицензия данного репозитория распространяется только на оригинальный исходный код этого проекта и не распространяется на материалы и элементы сервиса Яндекс Музыки.

## Возможности

### 🎨 Персонализация

* Установка любой собственной картинки в качестве фона.
* Автоматический подбор основных цветов интерфейса на основе выбранного фона.
* Возможность вручную изменять основные цвета интерфейса.
* Поддержка собственных визуальных настроек без привязки к стандартному оформлению.

### 🎵 Музыка

* Закрепление любимых альбомов для быстрого доступа.
* Удобный и расширенный поиск музыки.
* Расширенный выбор жанров.
* Обновлённое отображение караоке.
* Более удобная организация музыкального контента.

### 🌈 Аудиовизуализация

* Встроенная аудиовизуализация.
* Возможность включать и отключать визуализацию.
* Визуальные эффекты интегрированы непосредственно в интерфейс приложения.
