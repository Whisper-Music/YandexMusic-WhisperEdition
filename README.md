# Yandex Music Desktop

> Кастомный дизайнерский клиент для Яндекс Музыки с расширенными возможностями персонализации интерфейса.

Yandex Music Desktop — неофициальный сторонний клиент для Яндекс Музыки в редакции Whisper Music, созданный с упором на внешний вид, персонализацию и удобство использования.

Приложение позволяет настроить интерфейс под себя, изменить внешний вид плеера и сделать работу с музыкой более комфортной.

## Дисклеймер

**Yandex Music Desktop является неофициальным сторонним проектом.**

Проект не связан с Яндексом, не разрабатывается и не поддерживается компанией Яндекс.

Название «Яндекс Музыка», логотипы, музыкальные произведения, обложки, метаданные и другие материалы сервиса принадлежат их соответствующим правообладателям.

Лицензия данного репозитория распространяется только на оригинальный исходный код этого проекта и не распространяется на материалы и элементы сервиса Яндекс Музыки.

## Установка

Готовые версии приложения находятся в разделе [Releases](../../releases).

Для Windows доступен установщик `.exe`.

Для Linux в дальнейшем могут быть доступны соответствующие сборки (`.deb`, `.rpm`, `.AppImage`). Пока их можно собрать самостоятельно — см. ниже.

### Сборка под Linux

Нужны Rust, Node.js и системные библиотеки.

Debian / Ubuntu / Mint:

```bash
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev \
  libayatana-appindicator3-dev librsvg2-dev gstreamer1.0-plugins-good gstreamer1.0-libav
```

Fedora:

```bash
sudo dnf install webkit2gtk4.1-devel openssl-devel curl wget file libxdo-devel \
  libappindicator-gtk3-devel librsvg2-devel gstreamer1-plugins-good
sudo dnf group install "c-development"
```

Arch / Manjaro:

```bash
sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl xdotool \
  libappindicator-gtk3 librsvg gst-plugins-good gst-libav
```

Затем `npm install` и `npm run tauri build`.

Особенности Linux:

* **Трей.** Значок в трее работает через AppIndicator. В GNOME для этого нужно расширение
  «AppIndicator and KStatusNotifierItem Support» (в Ubuntu оно включено по умолчанию). Щелчок по значку
  в Linux всегда открывает меню — окно открывается пунктом «Открыть». Если значка в трее нет совсем,
  окно можно вернуть, просто запустив приложение ещё раз.
* **Вход.** Токен хранится в системной связке ключей (GNOME Keyring, KWallet, KeePassXC). Если связки ключей
  в системе нет, токен сохраняется в файл в папке настроек приложения, доступный только вашему пользователю.
* **Обои рабочего стола.** Поддерживаются GNOME, KDE Plasma, Cinnamon, MATE, Xfce, LXDE/LXQt, а также
  feh, nitrogen, hyprpaper и sway.
* **Звук и видеообои** воспроизводятся через GStreamer — без пакетов `gstreamer…-good` / `-libav` музыка и видео не заиграют.
* Режим глубокой экономии в трее (заморозка страницы) есть только в Windows: в Linux у движка окна такой функции нет.

## Возможности

### 🎨 Персонализация

* Установка любой собственной картинки в качестве фона.
* Автоматический подбор основных цветов интерфейса на основе выбранного фона.
* Возможность вручную изменять основные цвета интерфейса.
* Поддержка собственных визуальных настроек без привязки к стандартному оформлению.
* Тонкая настройка цветов любой панели и кнопки, с прозрачностью; один цвет можно сразу применить ко всем панелям или всем кнопкам.
* Четыре встроенных стиля оформления: «Неон», «Королевский», «Стимпанк» и «Lolitta».
* Свои темы в формате `.wmt`: к четырём встроенным стилям можно добавить сколько угодно своих — сделать копию любого стиля,
  поправить её и загрузить обратно (кнопка «Загрузить тему…» в настройках или перетаскиванием файла в окно) либо поделиться файлом.
  Тема может включать не только цвета, но и шрифты, оформление панелей, эффекты и собственный фон.
  Как устроены темы — [docs/THEMES.md](docs/THEMES.md), описание формата — [docs/WMT-FORMAT.md](docs/WMT-FORMAT.md),
  пример — [docs/examples/night-sky.wmt](docs/examples/night-sky.wmt).
* Список стилей в настройках не разрастается: текущий стиль подсвечивается, а когда стилей много, их можно свернуть
  в компактный вид — кружки с оформлением и названием.

### 🎵 Музыка

* Закрепление любимых альбомов для быстрого доступа.
* Удобный и расширенный поиск музыки.
* Расширенный выбор жанров.
* Обновлённое отображение караоке.
* Более удобная организация музыкального контента.
* История прослушивания и очередь следующих треков: их можно убирать и переставлять.
* Скачанные треки играют без интернета, а при отсутствии сети «Мне нравится» показывает скачанное.

### 🌈 Аудиовизуализация

* Встроенная аудиовизуализация.
* Возможность включать и отключать визуализацию.
* Визуальные эффекты интегрированы непосредственно в интерфейс приложения.
