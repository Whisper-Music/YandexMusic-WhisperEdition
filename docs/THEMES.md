# Темы оформления (`.wmt`)

В Whisper Music можно делать свои стили оформления и делиться ими одним файлом `.wmt`
(**W**hisper **M**usic **T**heme). Свой стиль появляется в настройках рядом со встроенными
(«Неон», «Королевский», «Стимпанк», «Lolitta») и меняет внешний вид целиком: цвета, шрифты, фон,
форму окон и кнопок, отступы, анимации.

Этот гайд — о том, как темы устроены и как сделать свою. Строгое описание формата для разработчиков
других приложений — в [WMT-FORMAT.md](WMT-FORMAT.md).

---

## Быстрый старт

1. **Настройки → Стиль оформления** — выбери стиль, который ближе всего к задумке.
2. **«Сохранить стиль в файл…»** — получится `.wmt` со всеми правилами этого стиля.
3. Открой файл в любом редакторе (VS Code, Notepad++…) и поправь:
   * `manifest` → `id` и `name` — иначе файл обновит ту же тему, а не создаст новую;
   * `tokens` — цвета, шрифты, свечение;
   * `@@ css whisper-music` — любые правила внешнего вида.
4. **«Загрузить тему…»** или просто перетащи файл в окно — в ряду стилей появится новая карточка.

Поправил ещё раз → загрузи тот же файл снова: тема с тем же `id` обновится.
Удалить тему — крестик на её карточке.

> Если тема сломала вид окна так, что настройки не найти, нажми **Ctrl+Shift+Backspace** —
> включится встроенный «Королевский».

---

## Из чего состоит тема

Тема бывает двух видов — как темы Telegram Desktop.

**Просто текстовый файл `.wmt`** — цвета, шрифты, CSS. Фоновой картинки нет: фон будет пустым,
но тема применится.

**Архив** — обычный `.zip`, переименованный в `.wmt`. Нужен, когда в теме есть фон или другие файлы:

```
моя-тема.wmt   (= zip)
├── theme.wmt        ← текст темы — обязательно
├── background.jpg   ← фон: всегда background.<расширение> (jpg, png, webp, gif, avif, bmp, mp4, webm, m4v, mov)
├── preview.png      ← по желанию: картинка для карточки в настройках
└── myfont.woff2     ← по желанию: шрифты и другие файлы, на которые ссылается CSS
```

Как поправить архивную тему: переименуй `.wmt` → `.zip`, распакуй, поправь `theme.wmt` или замени
`background.*`, запакуй обратно (хоть через «Сжать в zip» в Проводнике — можно вместе с папкой)
и снова назови `.wmt`.

### Текст темы

```
#WMT 1
# Строки с «#» в начале файла — комментарии.

@@ manifest
{ … }

@@ tokens
{ … }

@@ settings whisper-music
{ … }

@@ css whisper-music
.panel { … }
```

Секции начинаются строкой `@@ …`. JSON в секциях можно писать с комментариями `//` и лишними
запятыми — как в настройках VS Code. Если в файле ошибка, приложение покажет её с номером строки.

## `manifest` — что это за тема

```jsonc
{
  "id": "midnight-gold",        // латиница, цифры, дефис; по id тема обновляется при повторной загрузке
  "name": "Полночное золото",   // название на карточке
  "description": "Тёмное золото и синий акцент",
  "author": "Вадим",            // автор: в настройках — «Вадим · Полночное золото» (без автора — только название)
  "version": "1.0",
  "base": "royal",              // встроенный стиль-основа: neon | royal | steam | lolitta
  "preview": "asset:preview.png"// картинка для карточки (файл в архиве)
}
```

### Основа (`base`)

Часть оформления встроенных стилей сделана не в CSS, а в коде приложения. Эту часть тема получает
от своей основы:

| Основа | Что даёт |
|---|---|
| `neon` | ничего лишнего; свечение настраивается ползунком. Лучшая основа для «чистых» тем |
| `royal` | — |
| `steam` | увеличенный отступ кругового визуализатора вокруг кнопки «Моя волна» |
| `lolitta` | банты, жемчуг и розы на панелях (`.lodeco`), подбор контрастного текста под цвета, отступ визуализатора |

Всё остальное (рамки, кнопки, вкладки, шрифты) — это CSS, и он целиком лежит в файле темы.

## `tokens` — цвета, шрифты, эффекты

Общие значения, которые понимают все приложения Whisper.

```jsonc
{
  "color": {
    "accent": "#c9a24b",      // «Основной» цвет в настройках (#rrggbb)
    "accent2": "#8b1e2d",     // «Второй» цвет: кнопки, выделение (#rrggbb)
    "text": "#eadfc6",        // основной текст
    "muted": "#a39579",       // второстепенный текст
    "background": "#0e0b09"   // цвет фона окна, когда нет картинки
  },
  "effects": {
    "glow": 6,                // свечение, px (0–48)
    "panelOpacity": 0.92,     // непрозрачность панелей (0.2–1)
    "dim": 0.1,               // затемнение фоновой картинки (0–0.85)
    "backgroundBlur": 6
  },
  "font": {
    "body": "Tahoma, Arial, sans-serif",   // шрифт интерфейса
    "display": "Georgia, serif"            // шрифт заголовков (переменная --font-display)
  }
}
```

`accent`, `accent2`, `glow`, `panelOpacity`, `dim` — это стартовые значения: пользователь может
поменять их в настройках. `text`, `muted`, `font`, `background` применяются как есть и главнее
одноимённых переменных в CSS темы.

## `settings whisper-music` — какие настройки показывать

```jsonc
{
  "features": {
    "glow": false,          // ползунок «Свечение»
    "panelOpacity": false,  // ползунок «Прозрачность панелей»
    "animations": false     // галочка «Анимации интерфейса»
  },
  "colorOverrides": {       // значения из «Тонкой настройки цветов»
    "heading": "#f0e2b6"
  }
}
```

**`features`** говорит, что в теме есть, а чего нет. Если в теме нет свечения, ползунок «Свечение»
не нужен — поставь `"glow": false`, и он пропадёт из настроек. То же с прозрачностью панелей.
`"animations": false` скрывает галочку «Анимации интерфейса» и выключает анимации приложения.

Не указано — как у основы: свечение есть только у `neon`, прозрачность и анимации — у всех.

**`colorOverrides`** — сохранённая «Тонкая настройка цветов». Обычно появляется сама, когда
сохраняешь стиль в файл после настройки цветов. Цвет — `#rrggbb` или `#rrggbbaa` (последние две
цифры — непрозрачность: `ff` — сплошной, `80` — наполовину прозрачный, `00` — невидимый).

### Больше, чем CSS: ручка громкости, своя раскладка, кнопки на корпусе

Три поля для тем, которые перестраивают интерфейс целиком (пример — `docs/examples/retro-tv.wmt`,
телевизор с ручками):

```jsonc
{
  "controls": { "volume": "knob" },   // громкость — ручка
  "layout": "fixed",                  // тема сама задаёт расположение
  "buttons": { "power": "wave", "ch-up": "next" }   // свои кнопки: имя → действие
}
```

**`"controls": { "volume": "knob" }`** — кнопку громкости `#volBtn` можно крутить: зажать и тянуть
вверх или вправо — громче, вниз или влево — тише; колёсико и стрелки тоже работают, короткий щелчок
по-прежнему выключает звук. Громкость приходит в CSS числом `var(--vol)` от 0 до 1 (во всех темах),
так что поворот ручки рисуется одной строкой:

```css
#volBtn { rotate: calc(var(--vol) * 270deg - 135deg); }
.volpop { display: none; }      /* всплывающий ползунок больше не нужен */
```

**`"layout": "fixed"`** — режимы из «Настройки → Интерфейс → Расположение» (панель справа, свёрнутая панель,
нижняя панель в одну строку) не применяются, пока выбрана тема: вместо них в настройках надпись,
что расположение задаёт стиль. Выбор пользователя не теряется и вернётся с другим стилем.

**`"buttons"`** — кнопки, которых нет в приложении: например, кнопка «Моя волна» на корпусе, которая
видна на любой странице. Приложение создаёт `#thBtns > button.thbtn[data-th="имя"]`, а положение
и вид задаёт CSS темы (слой `#thBtns` — на всё окно, кнопки в нём — `position: absolute`).
Когда действие «включено» (волна играет, трек в лайках…), у кнопки класс `.on`.
Имя — латиница, цифры и дефис, до 16 кнопок. Действия:

| Действие | Что делает | `.on` |
|---|---|---|
| `wave` | включить/пауза «Моя волна» | волна играет |
| `play`, `next`, `prev` | пуск/пауза, следующий, предыдущий трек | `play` — что-то играет |
| `like`, `dislike` | лайк и «не нравится» играющему треку | трек в лайках / в «не нравится» |
| `shuffle`, `repeat` | перемешивание и повтор | режим включён |
| `mute`, `vol-up`, `vol-down` | звук выкл/вкл, громче и тише на 5 % | `mute` — звук выключен |
| `full` | обложка на весь экран | — |
| `sleep`, `more` | режим сна, меню «⋯» играющего трека | — |
| `page:wave`, `page:likes`, `page:stats`, `page:settings`, `page:profile` | открыть страницу | страница открыта |

Кнопка темы нажимает обычную кнопку приложения, поэтому ведёт себя так же и так же отключается
(`:disabled`), когда действие сейчас недоступно.

### Консоль вместо интерфейса

```jsonc
{
  "console": {
    "prompt": "user@whisper:~$",          // приглашение, до 40 символов
    "banner": "Добро пожаловать\nв терминал"  // приветствие, до 20 строк
  }
}
```

С `"console": true` (или объектом, как выше) вместо обычного интерфейса открывается командная
строка. Команды — приложения, тема их не добавляет и не меняет: она задаёт только приглашение,
приветствие и вид. Список обычных команд — `help`, справка по одной — `help <команда>`.
Вернуться к обычному интерфейсу — `gui`, аварийно — **Ctrl+Shift+Backspace**.

Вид консоли меняется через CSS темы:

| Селектор | Что это |
|---|---|
| `#cli` / `.cli` | вся консоль (по умолчанию текст — `var(--accent)`, подсветка — `var(--accent2)`) |
| `.cli-out` | область вывода |
| `.cl` | одна строка вывода; вид задают классы `.cmd` (введённая команда), `.err`, `.dim`, `.ok`, `.hl`, `.hd` (заголовок), `.banner` |
| `.cl.art` | рисунок из символов (котик, пластинка…): `white-space: pre`, без переносов |
| `.cl.live` | идущая анимация (визуализатор, метроном…) |
| `.cli.party` | включена команда `party` (по умолчанию — радужный `hue-rotate`) |
| `.cli-status` | строка состояния (что играет, прогресс, громкость) |
| `.cli-in`, `.cli-ps` | строка ввода и приглашение |

#### Скрытые команды

Их нет в `help` и в дополнении по Tab, но они работают в **любой** консольной теме — можно
упомянуть их в описании своей темы или в приветствии. `help <имя>` по скрытой команде отвечает.
Анимации останавливаются клавишей **Esc**, **Ctrl+C** или любой следующей командой.

| Команда | Что делает |
|---|---|
| `visual [bars\|wave\|line]` (`vis`) | аудиовизуализатор из символов: столбики с пиками, осциллограф или одна строка; `visual off` — стоп |
| `cat [vibe]` (`meow`, `мяу`) | котик; с аргументом-«файлом» — котик вместо файла; `cat vibe` — котик качается в такт басам |
| `cowsay [текст]` (`catsay`) | говорящий кот (да, кот); без текста — что сейчас играет |
| `vinyl` (`spin`) | пластинка, которая крутится, пока играет трек |
| `matrix` | «цифровой дождь» из нот, нулей и единиц |
| `party [off]` | радужная консоль на 30 секунд |
| `piano [темп] <ноты>` | сыграть ноты: `piano c e g c5`, `piano до ми соль`, `piano 200 c d e - e d c` (`-` — пауза, `#`/`b` — диез/бемоль, цифра — октава) |
| `metro [bpm] [доли]` (`metronome`) | метроном со звуком и индикатором долей: `metro 120`, `metro 90 3`, `metro off` |
| `tap` (`bpm`) | отстучи такт пробелом или Enter — консоль посчитает темп |
| `fortune` | случайный музыкальный факт |
| `fetch` (`neofetch`) | карточка клиента в духе neofetch: аккаунт, стиль, трек, лайки, палитра темы |
| `coffee` (`tea`, `кофе`, `чай`) | 418: чайник, но чашку нальёт |
| `hello` (`hi`, `привет`) | приветствие по времени суток |
| `whoami`, `uptime`, `ping` | аккаунт, время работы клиента, задержка до Яндекс Музыки |
| `sudo <команда>` | выполняет команду «с правами суперпользователя» |
| `rm`, `vim`, `nano`, `emacs` | попробуй |

Звук `piano` и `metro` идёт отдельно от музыки и не мешает ей; громкость — от общей громкости
приложения. `visual` и `cat vibe` подключают анализ звука, как визуализатор Моей волны.

### Настройки пользователя главнее темы

Всё, что пользователь выбрал в «Тонкой настройке цветов» (цвет и прозрачность любой панели, кнопок,
списка, меню…), всегда перекрывает CSS темы — даже правила с `!important`. Поэтому тема задаёт
вид «по умолчанию», а пользователь может довести его до любого своего: например, в теме со сплошными
серыми окнами сделать среднюю панель полупрозрачной поверх своих обоев. Если в теме у панели нет
обводки, а пользователь выбрал ей цвет обводки, приложение само нарисует рамку толщиной 1px.

Раздел «Сразу для всех» в начале окна настройки ставит один цвет во много мест сразу, например
во все панели (`titleBarBg`, `sideBg`, `mainBg`, `plBg`, `menuBg`) или во все кнопки
(`tabBg`, `navBg`, `btnBg`). В `colorOverrides` он записывается как обычные отдельные ключи,
поэтому для темы это ничем не отличается от ручной настройки каждого места.

## `css whisper-music` — внешний вид

Обычный CSS. Пиши так, будто твоя тема — единственная в приложении: приложение само привяжет
каждое правило к теме, и другие стили она не затронет.

| Ты пишешь | Работает как |
|---|---|
| `.panel { … }` | `:root[data-style="моя-тема"] .panel { … }` |
| `:root { --text: #fff; }` | переменные только этой темы |
| `:root[data-anim="on"] .tab { … }` | анимации только когда они включены |
| `@media (max-width: 880px) { … }` | как обычно |
| `@font-face { src: url(asset:font.woff2) }` | шрифт из архива темы |
| `@keyframes …` | как обычно |

Не работают: `@import` и ссылки на файлы из интернета — тема берёт только то, что лежит в ней самой.

Всё, чего нет в теме, берётся из общего оформления приложения. Поэтому тема может быть маленькой:
хоть одни `tokens`, хоть пара правил.

### Чтобы тема слушалась настроек

Пользователь меняет цвета, свечение и прозрачность в настройках — приложение передаёт их в CSS
через переменные. Если в теме написать цвет числом (`#000080`), настройка «Основной цвет» его
не изменит. Пиши переменными:

| Переменная | Что это |
|---|---|
| `var(--accent)` | «Основной» цвет |
| `var(--accent2)` | «Второй» цвет |
| `var(--text)`, `var(--muted)` | текст и второстепенный текст |
| `var(--glow)` | сила свечения, px (ползунок «Свечение») |
| `var(--glow-c)` | цвет свечения |
| `var(--panel-a)` | непрозрачность панелей, 0–1 (ползунок «Прозрачность панелей») |
| `var(--on-accent)` | цвет текста, читаемый на кнопке цвета `--accent2` |
| `var(--btn-fill)` | заливка выбранных кнопок (градиент из `--accent2`) |
| `var(--font-display)` | шрифт заголовков |
| `var(--vol)` | громкость числом 0–1 (для ручки громкости) |
| `var(--kick)` | удар бочки, 0–1 (на `.stage`, только при включённом визуализаторе) — например, `scale: calc(1 + var(--kick, 0) * .1)` |
| `--viz-gap` | задай на `.stage`, чтобы отодвинуть круговой визуализатор от кнопки «Моя волна», px |

Фон окна: картинку из настроек приложение ставит само (элемент `#bg`, затемнение — `#dim`).
Не прячь их в теме — иначе пользователь не сможет поставить свои обои.

### Основные элементы

| Селектор | Что это |
|---|---|
| `.titlebar` | верхняя полоса окна (название, кнопки свернуть/закрыть — `.tbctl button`) |
| `.tabs .tab`, `.tab.active` | вкладки сверху («Лайки» и закреплённые) |
| `.side` | боковая панель; `.side .nav` — её кнопки, `.nav.active` — выбранная |
| `.search` | поле поиска |
| `.main` | средняя часть; `.main[data-page="likes"]`, `…="wave"`, `…="settingsBtn"` — текущая страница |
| `.head h2`, `#title` | заголовок страницы |
| `.chip`, `.chip.active` | переключатели под заголовком («Лайки / Мои плейлисты») |
| `.list li`, `.list li.playing` | строки треков и играющий трек; `.t` — название, `.a` — исполнитель |
| `.likebtn`, `.likebtn.on`, `.morebtn` | сердечко и «⋯» в строке |
| `.player` | нижний плеер; `.playbtn` — «Пуск», `.modebtn.on` — включённые повтор и перемешивание |
| `#seek`, `#vol` | ползунки перемотки и громкости (`::-webkit-slider-runnable-track`, `::-webkit-slider-thumb`) |
| `.wavebtn` | большая кнопка «Моя волна» |

| `.waveorbits` | слой вокруг кнопки «Моя волна» с пятью `<i>` для колец и волн; по умолчанию скрыт (`display: none`) — включи его в теме. Пока волна играет, у него класс `.on`; при включённом визуализаторе — `.beats` |
| `.card` | блоки на странице настроек и статистики |
| `.stylecard` | карточки стилей |
| `.tmenu` | меню трека (`.tmenu button`) |
| `.toast` | всплывающие подсказки |
| `.login-box`, `.modalbox` | окна-диалоги |
| `.qpanel` | панель «Очередь и история» |
| `.panel` | общий класс панелей: боковой, нижней, выпадающих |

Удобнее всего подсматривать в инструментах разработчика или в файле, сохранённом из встроенного
стиля: там уже собраны все правила этого стиля.

### Анимации на события

Некоторые моменты приложение отмечает классом — тема может повесить на него свою анимацию.
Если анимации нет (или выключены «Анимации интерфейса»), всё происходит сразу, как обычно.

| Событие | Что делает приложение | Как использовать |
|---|---|---|
| Смена трека | обложке плеера `.player .cover` ставит `.flip-out`, ждёт конца этой анимации, меняет картинку (новая уже загружена) и ставит `.flip-in` | обложка «уходит» и «приходит»: в «Королевском» так сделан переворот монетой |
| Нажатие «Моя волна» | кнопке `.wavebtn` ставит `.stamp` заново при каждом нажатии | отклик на нажатие: в «Королевском» — оттиск печати и золотое кольцо |
| Волна играет | слой `.waveorbits` получает `.on`, а анимации с именем `neonSpin` внутри него ускоряются в 2,4 раза (плавно, без рывка) | крутящиеся кольца вокруг кнопки, как в «Неоне» |
| Смена страницы | у `.main` меняется `data-page` | у каждой страницы своё имя анимации — тогда она перезапускается при переходе (пример — «переключение канала» в `retro-tv.wmt`) |
| Включение стиля | — | анимация, заданная в CSS темы, сама запускается при запуске приложения с этой темой и при её выборе (пример — включение экрана телевизора в `retro-tv.wmt`) |

```css
/* переворот обложки, как в «Королевском» */
:root[data-anim="on"] .player .cover.flip-out { animation: coinOut .2s ease-in forwards; }
:root[data-anim="on"] .player .cover.flip-in  { animation: coinIn .5s ease-out; }
@keyframes coinOut { to   { transform: perspective(300px) rotateY(90deg); } }
@keyframes coinIn  { from { transform: perspective(300px) rotateY(-90deg); } }

/* анимация при смене страницы: разные имена с одинаковыми кадрами */
:root[data-anim="on"] .main[data-page="likes"] { animation: pageA .4s; }
:root[data-anim="on"] .main[data-page="wave"]  { animation: pageB .4s; }
@keyframes pageA { from { opacity: 0; } }
@keyframes pageB { from { opacity: 0; } }
```

Если анимация должна закончиться невидимой (например, шторка, которая открывает экран), сделай
невидимым и сам элемент без анимации (`opacity: 0; visibility: hidden`), а анимацию включай только
при `:root[data-anim="on"]` — тогда с выключенными анимациями шторка просто не появится.

### Если тема перестраивает интерфейс целиком

Пример — `docs/examples/retro-tv.wmt`: всё окно — телевизор, экран со страницами слева,
ручки и кнопки справа. Что пригодилось:

* **`"layout": "fixed"`** в `settings` — иначе режимы «Расположения» (панель справа, свёрнутая панель)
  будут перестраивать окно поверх твоей раскладки.
* **Сетка окна.** Окно — сетка `.app`. Чтобы задать свою, пиши `body > .app { grid-template-… }` —
  правило с одним `.app` слабее правил расположения приложения.
* **Разобрать нижний плеер.** `.player, .player > .pcenter, .player > .pright { display: contents; }` —
  обложка с названием (`.pinfo`), полоса перемотки (`.seekrow`), кнопки (`.ctrls`) и громкость (`.volwrap`)
  становятся отдельными частями `.app`: их можно ставить куда угодно через `grid-area` или
  `position: absolute` (относительно `.app`, у неё `position: relative`).
* **Панели и `position: absolute`.** У `.panel` есть `backdrop-filter`, а с ним вложенные элементы с
  `position: absolute/fixed` считаются от панели, а не от окна. Выносишь что-то из панели — поставь ей
  `backdrop-filter: none`.
* **Очередь** (`.qpanel`) приложение ставит по краям `.main` и плеера. Если плеера как блока больше нет,
  задай место сам: `.qpanel { top: …px !important; bottom: …px !important; right: …px !important; }`.
* **Декор без лишних элементов.** `.app::before`, `.app::after`, `body::before`, `body::after` в своей теме
  свободны: в телевизоре это рамка кинескопа, строки развёртки поверх экрана, шторка включения и решётка динамика.
* **Свои обои пользователя** можно не прятать, а «вписать»: `#bg, #dim { inset: …; border-radius: … }` —
  в телевизоре обои стали картинкой на экране.
* **Пиксельный шрифт** чёткий только в своих размерах (для шрифта 8×16 — 16 и 32 px) и без дробного
  `letter-spacing`. Размер всего текста можно закрепить одним правилом: `.app * { font-size: 16px !important; }`.

## Библиотека тем

**Настройки → Оформление → «Библиотека тем»** — готовые темы из репозитория
[Whisper-Music/whisper-themes](https://github.com/Whisper-Music/whisper-themes): превью, описание, поиск,
установка в один клик. Темы разложены по папкам: **Whisper Music** (от автора приложения), **Пользователи**
и **По артистам** (внутри — по исполнителям). Поиск ищет сразу во всех папках, Esc возвращает к папкам. Тема сразу включается; если в библиотеке вышла новая версия (`manifest.version`),
на её карточке появится «Обновить».

Приложение скачивает оттуда только `index.json`, `previews/<папка>/<id>.*` и `themes/<папка>/<id>.wmt`
(папки — `whisper`, `community`, `artists`) из ветки `main` —
этим занимается Rust (`src-tauri/src/themelib.rs`), сама страница в сеть не ходит. Установленная тема
проходит ту же проверку, что и файл, загруженный вручную.

Чтобы твоя тема появилась в библиотеке, положи её в `themes/community/` того репозитория (тема в стиле
артиста — в `themes/artists/`, с `"artist": "Имя"` в `manifest`), запусти
`node tools/build-index.js` и открой pull request — подробности в его README.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Это не файл темы: первая строка должна быть «#WMT 1»» | в начале файла должна быть строка `#WMT 1` |
| «ошибка в JSON … (строка N)» | открой файл на строке N: не хватает запятой или кавычки |
| «manifest.id …» | `id` — только маленькие латинские буквы, цифры и дефис |
| «… — это встроенный стиль» | `id` не может быть `neon`, `royal`, `steam` или `lolitta` |
| «В архиве нет файла theme.wmt» | в zip должен лежать файл `theme.wmt` |
| Цвета из настроек не меняют тему | в CSS темы цвета написаны числами — замени на `var(--accent)` / `var(--accent2)` |
| Не ставится свой фон | в CSS темы спрятаны `#bg` или `body { background: … !important }` |
| Правило из CSS не срабатывает | правило встроенного оформления сильнее — добавь селектору уточнение или `!important` |
| Тема перестроила окно, а включение «Панель справа» её ломает | добавь в `settings` `"layout": "fixed"` |
| Очередь открывается тонкой полоской | у плеера `display: contents` — задай место `.qpanel` сам (см. «Если тема перестраивает интерфейс целиком») |
| Кнопки темы из `buttons` не видно | у них нет размера и места, пока их не задал CSS: `.thbtn[data-th="…"] { right: …; bottom: …; width: …; height: … }` |
| Буквы пиксельного шрифта размыты | размер шрифта не кратен «родному» или есть дробный `letter-spacing` |
| Вид окна сломан | **Ctrl+Shift+Backspace** — вернуть встроенный стиль |

Загружать одну и ту же тему можно сколько угодно раз: тема с тем же `id` просто обновляется.
